# ДЗ №9. Анализ событий информационной безопасности

## Цель работы

Анализ и визуализация событий информационной безопасности с использованием Python.

## Используемые библиотеки

- Pandas — загрузка и анализ данных.
- Matplotlib — настройка и отображение графика.
- Seaborn — построение диаграммы.

## Установка зависимостей

`pip install -r requirements.txt`

## Запуск программы

`python3 analysis.py`

## Результаты анализа

- Проанализировано 100 событий информационной безопасности.
- Выявлено 9 уникальных сигнатур.
- Построена горизонтальная столбчатая диаграмма распределения событий по полю signature.
